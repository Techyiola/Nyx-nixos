# Nyx — CachyOS i3 rice → NixOS + Home Manager

This flake reproduces the CachyOS / i3 setup on a fresh NixOS install:

- **NixOS unstable**, host `Nyx-X`, user `techyiola`
- i3 + Polybar + Rofi + Dunst + Picom + Feh (X11, managed by **Ly**)
- Fish + Starship + Eza, with the old custom fish functions
- Ghostty / Alacritty, Btop, Yazi, Neovim (LazyVim), Zen Browser
- PipeWire, NetworkManager, Bluetooth (Blueman / bluetui), UPower,
  power-profiles-daemon, Docker, zram
- NVIDIA RTX 2050 via PRIME render offload, AMD Cezanne iGPU as primary
- GTK (Adwaita-dark + Papirus-Dark + Bibata cursors) and Qt (qt5ct / Kvantum)
- The `~/.local/bin` helper scripts, + a wrapped `screenshot` build
- The original `battery-notify` and `keep-awake-display` systemd user units

The repository is designed to live at **`~/nixos-config`**. Two directories are
linked out of the Nix store so they stay writable:

| Path | Why |
|---|---|
| `~/.config/nvim` | LazyVim writes `lazy-lock.json` |
| `~/.config/i3` | `set-wallpaper.sh` replaces `wallpaper.png` |

Everything else is a normal read-only Home Manager symlink. Edit the files in
this repo and run `sudo nixos-rebuild switch --flake ~/nixos-config#nixos`.

---

## 1. Before installing

1. Install NixOS (graphical ISO is easiest) on the target disk.
   Keep the btrfs subvolume layout you want — `@`, `@home`, `@var_log`, etc.
   Do **not** copy `/etc/fstab` from CachyOS; NixOS uses `fileSystems.*`.
2. During the installer, or from a live environment, clone this repo to the
   user's home:

   ```sh
   git clone <your-remote> ~/nixos-config
   ```

   If you are installing before the user exists, clone to
   `/mnt/home/techyiola/nixos-config` after mounting the target, or clone it
   later and re-run `nixos-install` / `nixos-rebuild`.

3. Confirm the machine values in `hosts/nixos/configuration.nix`:
   - `networking.hostName`
   - `time.timeZone`, `i18n.defaultLocale`
   - `hardware.nvidia.prime.amdgpuBusId` / `nvidiaBusId`
   - `boot.kernelPackages` (`linuxPackages_zen` by default)
   - `system.stateVersion` (use the release you install)

   Bus IDs come from `lspci | grep -E 'VGA|3D'` on the target. The values in the
   file (`PCI:4:0:0` for AMD, `PCI:1:0:0` for NVIDIA) are from the original
   machine; check them.

---

## 2. Generate the hardware configuration (required)

`hosts/nixos/hardware-configuration.nix` is a **placeholder** and will not boot
as-is.

```sh
# after mounting the target root at /mnt
sudo nixos-generate-config --root /mnt

# replace the placeholder with the real file
cp /mnt/etc/nixos/hardware-configuration.nix \
   /mnt/home/techyiola/nixos-config/hosts/nixos/hardware-configuration.nix
```

The generated file should define `fileSystems`, `swapDevices`,
`boot.initrd.availableKernelModules`, and `boot.kernelModules`. The rest of the
hardware setup (CPU microcode, graphics, NVIDIA, zram) is already in
`configuration.nix`.

---

## 3. Install

```sh
sudo nixos-install --flake /mnt/home/techyiola/nixos-config#nixos
```

The flake output is named `nixos` (not `Nyx-X`):

```
nixosConfigurations.nixos
```

After the first boot, set a password (it is intentionally not stored in this
repo):

```sh
passwd techyiola
```

Then rebuild whenever you change the repo:

```sh
sudo nixos-rebuild switch --flake ~/nixos-config#nixos
```

and optionally:

```sh
nix flake update --flake ~/nixos-config   # bump nixpkgs / HM / Zen
nix-collect-garbage -d                    # old generations (also `debloat`)
```

## 5. What is intentionally not managed

- **Passwords / SSH keys / tokens**: no secrets are in this repo.
  The old `~/.config/opencode/service.json` contained a plaintext credential;
  it was **excluded**. Rotate that credential if it was ever pushed anywhere.
- **Browser profiles and personal data** (Zen/Firefox profiles, `~/Downloads`,
  `~/Documents`, etc.).
- **`~/.config/fish/fish_variables`**: generated by fish at runtime.
- **`~/.zshrc` and the CachyOS zsh config**: Fish is the login shell here.
  Add `programs.zsh` to `home/default.nix` if you want zsh back.
- **AUR-only tools**: `fetch` → replaced by `fastfetch --logo arch`;
  the Arch update widget and `arch_updates.sh` are gone; `debloat` / `gut`
  now call `nix-collect-garbage -d`.
- **`redshift`**: it was referenced but not configured on the old machine;
  the autostart line is commented out. Use `services.redshift` if wanted.
- **`s-nail` / any mail client**: add a nixpkgs equivalent if you need one.
- **Kvantum theme `KvMojave`** (AUR): Home Manager enables Kvantum with its
  default theme; drop a packaged theme in `qt.kvantum.themes` if desired.

## 6. Layout

```
flake.nix                     inputs: nixpkgs, home-manager, zen-browser
hosts/nixos/
  configuration.nix           system config
  hardware-configuration.nix  REPLACE with nixos-generate-config output
home/
  default.nix                 shell, git, GTK/Qt, XDG, session vars
  packages.nix                personal dev/CLI packages
  dotfiles.nix                config symlinks + ~/.local/bin scripts
  scripts.nix                 wrapped screenshot build
  systemd.nix                 battery-notify + keep-awake-display units
dotfiles/                     the cleaned rice configs
```

## 7. Notes on the migration

- **Kernel**: `linuxPackages_zen` is the closest packaged analogue of
  CachyOS's BORE kernel. Switch to `linuxPackages_cachyos` only if your nixpkgs
  revision provides it; otherwise `linuxPackages_zen` is the supported choice.
- **Picom**: the old `dual_kawase` blur needs the ibhagwan fork, which nixpkgs
  does not package. The config uses the built-in `gaussian` method instead.
- **Zen**: not in nixpkgs. The `zen-browser` flake's default package installs
  the binary `zen-beta` and desktop ID `zen-beta.desktop`.
- **screenshot**: built with `wrapGAppsHook3` so PyGObject/PyCairo, GTK
  typelibs, ImageMagick `import`, `xclip`, `wl-copy`, `rofi` and `xprop` are all
  on its PATH. It is installed to `~/.local/bin/screenshot` because the i3
  config calls that absolute path.
- **`lock`**: uses `i3lock` from `i3lock-color` (the package provides both
  names).
- **Fonts**: Nerd Fonts (JetBrains Mono, Meslo LG), Fira Sans, Noto, DejaVu,
  Liberation, Cantarell, Font Awesome.
- **Theme**: Adwaita-dark + Papirus-Dark + Bibata-Modern-Classic, matching the
  old GTK settings. The old `gtk.css` text colour is preserved.

## 8. Troubleshooting

- **A file already exists / collision**: Home Manager is configured with
  `home-manager.backupFileExtension = "hm-backup"`, so the first switch moves
  conflicting files to `*.hm-backup`. Remove that line once everything is
  managed.
- **Ly starts the wrong session**: the default session is `"i3"`. Check
  `services.displayManager.defaultSession`. The assertion accepts only names
  that NixOS actually generated (e.g. `i3`), not `none+i3`.
- **NVIDIA suspend/resume issues**: try `hardware.nvidia.open = false`, or set
  `powerManagement.enable = false`, then rebuild.
- **`prime-run` missing**: it comes from
  `hardware.nvidia.prime.offload.enableOffloadCmd = true`.
- **Wallpaper script fails**: `~/.config/i3` is an out-of-store symlink to
  `~/nixos-config/dotfiles/i3`; make sure the repo is still at that path.
- **Nix not installed yet**: this repo cannot be evaluated on the old CachyOS
  host. Build it on the target, or install Nix and run
  `nix flake check` before installing NixOS.
